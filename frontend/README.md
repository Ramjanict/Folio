## Folio

A lending library. Readers browse the catalog and borrow copies, authors submit manuscripts, and admins publish titles, manage members, and run the loan desk.

## Technology Stack
TypeScript<br>
React<br>
Tailwind CSS<br>
Redux Toolkit<br>
react-router-dom<br>

## Instructions to Run Locally
npm install<br>
npm start
